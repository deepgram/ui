# Examples

| Directory | Description |
|-----------|-------------|
| [`basic/`](basic/) | Minimal example with AgentConversation, AgentMessage, and AgentStartButton |

## Prerequisites

All examples require a backend endpoint that returns a short-lived Deepgram API token. See the [Deepgram docs](https://developers.deepgram.com/docs/voice-agent) for details.

## Adding Examples

New examples should be self-contained React components in their own directory with a README explaining how to run them.
